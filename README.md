# 🎓 College Event Portal

A web-based College Event Portal designed to provide students with an easy and organized platform to explore, register, and participate in various college events.

The portal helps students stay updated about upcoming academic, technical, cultural, and extracurricular events conducted by the college.

---

## 📌 Project Overview

The College Event Portal is a user-friendly web application developed to simplify the process of discovering and managing college events.

Instead of depending on multiple notices or announcements, students can use the portal to view event information such as event name, date, time, venue, category, and registration details in one place.

The project demonstrates the use of front-end web development technologies to create an interactive and organized event management interface.

---

## ✨ Features

- 🏠 Home Page
- 📅 Upcoming Events
- 🎓 Academic Events

- 🎭 Cultural Events
- 🏆 Sports and Other Activities
- 📝 Event Registration
- 📋 Event Details
